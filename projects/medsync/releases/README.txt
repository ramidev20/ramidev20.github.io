Put each version of this app in its own folder here, named after the version:

  releases/1.0.0/your-app-1.0.0.apk
  releases/1.1.0/your-app-1.1.0.apk
  releases/1.1.0/your-app-1.1.0-setup.exe
  releases/1.2.0-beta/your-app-1.2.0-beta.apk   (a "-beta" folder shows as a pre-release)

Optional: a notes.txt in a version folder becomes that version's release notes.
Its first line can set the date:

  Date: 2026-11-10
  - Offline mode
  - Faster startup

The page at /medsync/ lists the versions automatically, newest first.
